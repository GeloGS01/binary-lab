# Binary Lab

Interactive binary <-> decimal practice for CS 8 (Assumption College Sriracha).
No login. Open: https://gelogs01.github.io/binary-lab/

Personal best scores stay in the browser. The only thing sent online is a **Beat the clock**
score a student chooses to post (nickname + class + score) to the global Top 10, which is stored in
the teacher's Google Sheet via the Apps Script in `apps-script/Code.gs` (set `SCORE_URL` in `index.html`).
